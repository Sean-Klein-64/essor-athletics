Sur ta montre Garmin

  1. App Garmin Connect → Plus → Entraînement et planification → Séances d'entraînement → Créer → Course à pied.
  2. Ajoute les étapes ci-dessous, dans l'ordre. Pour l'allure : Cible → Allure, puis les deux valeurs.
  3. Enregistre, puis Envoyer vers l'appareil. Sur la montre : Course → Entraînement → Mes séances.

    Avec le fichier · sur un ordinateur

    1. Télécharge le fichier de la séance
    2. Branche ta montre à l'ordi avec son câble
    3. Copie le fichier dans GARMIN › NewFiles
    4. Débranche. Sur la montre : Course › Entraînement › Mes séances

    Sur Mac, si la montre n'apparaît pas, installe l'app gratuite OpenMTP pour voir ses dossiers. Depuis le téléphone, le plus simple reste les étapes ci-dessus dans l'app Garmin Connect.
